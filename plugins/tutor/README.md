# Semantier Tutor

Tutor is a native Hermes plugin with a bundled skill for learning from selected project material. Its five tools cover learning plans, explanations and hints, practice, assessment and progress. An authenticated, compatible Semantier host must provide the scoped Tutor operations. Source identities, attempt history and assessment evidence belong to the learner's governed project.

The mastery estimate uses recent independently graded attempts. The progress view identifies contributing assessments and distinguishes assisted work and unavailable evidence. Follow the source citations to inspect the basis of the feedback.

The package includes adapted DeepTutor code and teaching instructions. See [UPSTREAM.md](UPSTREAM.md) for the pinned sources and license.
