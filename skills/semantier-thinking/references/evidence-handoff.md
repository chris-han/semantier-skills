# Minimal evidence and reasoning handoff

Use this only for consequential multi-step work crossing inquiry, decision, writing, ethics or organizational references. Do not create a mandatory persisted ledger.

Carry, in existing task context or authored artifact:

| Field | Purpose |
| --- | --- |
| Question/goal | Exact issue and requested deliverable |
| Scope & dates | Affected population, organization, setting and reference time |
| Claims | Key propositions, preserved modality, who asserts them |
| Evidence | Source file/URL and bounded locator; direct/external check status |
| Inferences | Warrant/assumption, analyst-reconstructed flag, limitations |
| Contradictions | Strongest supported counterevidence; scope differences |
| Values/constraints | Owner's stated priorities, obligations and hard limits |
| Unknowns | Which missing facts could flip conclusion; CANNOT_ASSESS vs FALSE |
| Conclusion | Supported recommendation/argument, qualification and revision trigger |

Traceability invariants:
- A “reported” claim cannot become “verified” merely because another skill restates it.
- Citation location and version/date survive summary. Do not silently strip contrary evidence.
- Agent interpretation is not domain authority, statutory interpretation, signer provenance or independent benchmark gold.
- Route to a new skill only if its distinct inquiry changes the finish condition. Otherwise continue current work.
- An updated source triggers selective revision of dependent claims, not blanket deletion or automatic reversal of unaffected information.
